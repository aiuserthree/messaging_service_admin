# 톡벨 어드민 시스템 프로젝트 명세서

## 1. 프로젝트 개요

### 1.1 프로젝트 정의
- **프로젝트명**: Tokbell Admin System (톡벨 어드민 시스템)
- **프로젝트 목적**: 메시징 서비스(SMS, LMS, MMS, 알림톡, 브랜드 메시지)의 운영 및 관리를 위한 통합 관리자 시스템 제공
- **핵심 가치**:
  1. **통합 운영**: 다양한 메시징 채널(SMS/LMS/MMS, 카카오 알림톡/브랜드 메시지)의 통합 관리
  2. **효율적 심사**: 발신번호 및 템플릿의 체계적인 승인/반려 프로세스
  3. **실시간 모니터링**: 발송 현황, 시스템 상태, 통계의 실시간 확인
  4. **보안 관리**: 접근 권한 제어, 감사 로그, 보안 정책 관리
  5. **비즈니스 인사이트**: 발송 통계, 매출 리포트, 회원 분석 제공

### 1.2 목표 사용자

### 2.2 핵심 기능 명세

#### 기능 ID: F001
**기능명**: 대시보드
**우선순위**: 필수 (P0)
**기능 설명**: 시스템 전반의 현황을 한눈에 파악할 수 있는 메인 화면

**사용자 스토리**:
- As a 관리자
- I want 시스템 전반의 현황을 한눈에 확인하고 싶습니다
- So that 빠르게 처리해야 할 업무를 파악할 수 있습니다

**기능 상세**:
- 입력: 없음 (자동 로드)
- 처리: 각종 통계 데이터 집계 및 표시
- 출력: 통계 카드, 최근 발송 내역, 승인 대기 목록

**수용 기준**:
- [x] 오늘 발송 건수, 충전 금액, 신규 가입자 수 표시
- [x] 승인 대기 건수, 처리 대기 문의 건수 표시
- [x] 시스템 상태 표시 (정상/경고/오류)
- [x] 최근 24시간 발송 내역 테이블 표시
- [x] 승인 대기 목록에서 바로 검토 페이지 이동 가능

**UI/UX 요구사항**:
- 화면 구성: 6개 통계 카드 (3x2 그리드), 최근 발송 테이블, 승인 대기 테이블
- 인터랙션: 카드 클릭 시 상세 페이지 이동, 테이블 행 클릭 시 상세 팝업
- 피드백: 실시간 데이터 갱신 시 부드러운 애니메이션

#### 기능 ID: F002
**기능명**: 회원 관리
**우선순위**: 필수 (P0)
**기능 설명**: 서비스 이용 회원의 조회, 관리, 상태 변경 기능

**사용자 스토리**:
- As a 운영 관리자
- I want 회원 정보를 검색하고 상세 내역을 확인하고 싶습니다
- So that 회원 관련 문의에 빠르게 대응할 수 있습니다

**기능 상세**:
- 입력: 검색 조건 (회원명, 이메일, 유형, 상태, 기간)
- 처리: 회원 목록 조회, 상세 정보 조회, 상태 변경
- 출력: 회원 목록 테이블, 회원 상세 팝업

**수용 기준**:
- [x] 회원 검색 (이름, 이메일) 및 필터 (유형, 상태, 기간)
- [x] 회원 상세 정보 5개 탭 (기본, 기업, 계정, 활동, 메모)
- [x] 계정 정지/해제, 비밀번호 초기화, 계정 삭제 기능
- [x] 잔액 충전/차감, 보너스 지급/차감 기능
- [x] 연관 정보 조회 (발송내역, 발신번호, 결제내역, 문의내역)

**비즈니스 규칙**:
- 계정 정지 시 해당 회원의 발송 서비스 자동 중단
- 잔액 조정 시 반드시 사유 입력 필수
- 계정 삭제는 2중 확인 필요

**우선순위**: 필수 (P0)

- 입력: 검색 조건, 검토 의견, 승인/반려/보완요청 선택
- 처리: 서류 검증, 상태 변경, 알림 발송
- 출력: 승인 대기 목록, 상세 검토 팝업, 처리 결과

**수용 기준**:
- [x] 승인 대기 목록 조회 (신청일시, 회원, 발신번호, 통신사, 명의자, 명의구분)
- [x] 서류 다운로드 및 미리보기
- [x] 개별 승인/반려/보완요청 처리
- [x] 일괄 승인/반려 처리
- [x] 검토 메모 및 이력 관리

**비즈니스 규칙**:
- 휴대폰 번호는 본인인증 필수
- 타인/타사 명의는 위임장 필수
- 반려 시 사유 입력 필수
- 보완 요청 시 기한 설정 필수

### 3.2 주요 화면 명세

#### 화면 ID: S001
**화면명**: 대시보드
**화면 목적**: 시스템 전반의 현황을 한눈에 파악

**화면 구성 요소**:
1. **헤더 영역**
   - 요소: 페이지 타이틀 "대시보드", 관리자 정보, 로그아웃 버튼
   - 기능: 현재 로그인 관리자 확인, 로그아웃

2. **통계 카드 영역**
   - 요소: 6개 stat-card (오늘 발송, 충전금액, 신규가입, 승인대기, 문의대기, 시스템상태)
   - 레이아웃: 3열 그리드 (반응형: 태블릿 2열, 모바일 1열)

3. **최근 발송 내역 영역**
   - 요소: 테이블 (발송일시, 회원, 메시지타입, 건수, 성공, 실패, 상태)
   - 레이아웃: 카드 형태의 테이블

4. **승인 대기 목록 영역**
   - 요소: 테이블 (신청일시, 회원, 유형, 내용, 상태, 관리버튼)
   - 액션: 검토 버튼 → 해당 페이지로 이동

**인터랙션 명세**:
- 통계 카드 호버 → 약간의 그림자 효과
- 검토 버튼 클릭 → 해당 승인 대기 페이지로 이동
- 테이블 행 호버 → 배경색 변경

**화면 전환 규칙**:
- 진입 조건: 로그인 성공 후 기본 진입, 사이드바 "대시보드" 클릭
- 이탈 조건: 사이드바 다른 메뉴 클릭, 로그아웃

## 5. 비기능 요구사항

### 5.1 사용성 요구사항
- **접근성**: WCAG 2.1 Level AA 준수
- **학습 용이성**: 신규 관리자가 30분 내 주요 기능 숙지 가능
- **효율성**: 모든 주요 기능 3번 클릭 이내 접근 가능
- **오류 방지**: 중요 작업 (삭제, 정지) 전 확인 다이얼로그 표시

### 5.2 성능 요구사항
- **응답 시간**: 
  - 페이지 로드: 2초 이내
  - 검색 결과 표시: 1초 이내
  - 모달 오픈: 0.5초 이내
- **처리량**: 동시 관리자 10명 이상 지원
- **데이터 용량**: 100만 건 이상 발송 내역 처리 가능

### 5.3 보안 요구사항
- **인증**: JWT 기반 세션 관리, 세션 타임아웃 30분
- **권한**: 역할 기반 접근 제어 (RBAC)
- **데이터 보호**: 민감 정보 마스킹 (이메일, 전화번호, 금액)
- **감사**: 모든 관리자 활동 로깅
