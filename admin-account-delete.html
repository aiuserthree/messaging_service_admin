관리자 계정 생성·삭제(탈퇴·말소)·권한 변경 관리대장
관리자 계정 생성·삭제와 권한 변경은 요청 → 승인 → 처리 순서로 진행하며, 처리는 최고 관리자만 할 수 있고 실행 즉시 반영됩니다. 승인자와 처리자는 같은 사람일 수 없습니다(직무 분리). 처리 시 관리자 이름 · 계정 이메일(아이디) · 소속 · 변경 전·후 권한 · 사유 · 요청자 · 승인자 · 처리자 · 요청·승인·처리 일시가 관리대장에 기록되며, 기록은 수정·삭제할 수 없습니다. 권한 그룹 자체의 생성·수정·삭제 이력도 함께 관리합니다. 외부 도메인 계정은 계약 근거·도메인 소유 확인·내부 책임자·사용 기한(최대 6개월)을 함께 기록합니다. (운영정책서 11.2.2 — 권한이 불필요해진 경우 지체 없이 말소하고 기록으로 관리, 분기 1회 검토·감사)
현재 로그인한 계정(-)은 최고 관리자가 아니므로 관리대장 조회만 가능합니다. 계정 생성·삭제 및 권한 변경 버튼은 표시되지 않습니다. 처리가 필요하면 최고 관리자에게 요청하세요.

계정 정보
사내 도메인(@ibank.co.kr) 발급이 원칙입니다.
외부 도메인 계정 통제 항목 — 협력사 인력에 한해 발급 (모두 필수)
외부 도메인 계정에는 최고 관리자 권한을 부여할 수 없습니다. 사용 기한이 지나면 자동 정지되며, 내부 책임자가 분기 1회 소유·재직 여부를 재확인합니다.
요청 · 승인 · 처리
생성 즉시 계정 이메일로 비밀번호 설정 링크가 발송되며, 관리자는 초기 비밀번호를 알 수 없습니다. 최초 로그인 시 보안 로그인(다중 인증) 등록이 필수입니다. 생성 이력은 수정·삭제할 수 없습니다.
