국외·우회 접속 탐지·차단 방법 (설명자료)

전송자격인증 2.2-01 국외 IP 차단 · 2.2-02 우회접속 통제 — (주)아이뱅크 톡벨 문자 발송 서비스

1. 처리 흐름

  1. 1
    요청 수신
    사용자 웹 사이트·발송 API·관리자 페이지로 들어오는 모든 요청은 웹 방화벽(WAF)·API 게이트웨이를 거쳐 접속 필터에 도달합니다. 로그인 전 요청(로그인·회원가입 화면)도 동일하게 검사하므로 계정이 없는 상태의 접근도 차단됩니다.
  2. 2
    클라이언트 IP 식별 (프록시 헤더 신뢰 범위)
    TCP 연결 IP 를 기준으로 하며, X-Forwarded-For 는 자사 로드밸런서(신뢰 프록시)가 추가한 값만 사용합니다. 이용자가 임의로 넣은 헤더 값은 무시하여 IP 위조를 막습니다. IPv4·IPv6 모두 판정합니다.
  3. 3
    GeoIP 국가 판정
    MaxMind GeoIP2 Country 로 국가를 판정하고 KISA 국가별 IP 할당 정보로 교차 검증합니다. KR 이 아니면 차단 대상입니다. 판정 불가·DB 조회 장애 시에도 허용하지 않고 기본 차단(Fail-close)합니다.
    R-GEO-01 국외 IPR-DEF-01 판정 불가
  4. 4
    우회접속 판정 (IP 평판·Tor 목록·ASN·헤더)
    국가가 KR 이더라도 IP 평판 DB(VPN·공개/익명 프록시·호스팅), Tor 출구 노드 목록(1시간 주기 동기화), ASN 기반 호스팅·IDC 분류, 프록시 경유 헤더(Via·Forwarded), 접속 환경 국가 불일치를 검사하여 하나라도 해당하면 차단합니다.
    R-BYP-01 VPNR-BYP-02 프록시R-BYP-03 TorR-BYP-04 호스팅·IDCR-BYP-05 국가 불일치
  5. 5
    차단 및 로그 기록
    HTTP 403 과 함께 차단 안내 화면(API 는 오류 코드 E403_ACCESS_BLOCKED)을 반환하고, 세션 발급·인증번호 발송·문자 발송 등 후속 처리는 수행하지 않습니다. 로그인 상태였다면 세션을 즉시 만료합니다. 계정·접속 IP·일시·국가·탐지 유형·사유·결과·요청 경로·User-Agent·판정 근거(DB 버전)를 차단 로그에 기록합니다.
  6. 6
    반복 시도 알림·모니터링
    동일 계정·IP 에서 10분 내 3회 이상 차단되면 보안 담당자(-)에게 알림을 발송하고 해당 계정·IP 를 모니터링 대상으로 지정합니다. 관리자 계정은 1회 차단부터 즉시 알림합니다.

3. 로그 기록 및 보관

  • 기록 항목: 차단일시, 로그 ID, 대상 시스템, 계정(미로그인 포함), 접속 IP, 국가, 탐지 유형, 적용 규칙, 차단 사유, 결과, 요청 메서드·경로, User-Agent, 세션, 판정 근거 DB·버전
  • 보관 기간: 3년 (최소 1년 이상 보관 기준 충족)
  • 무결성: 추가 전용(append-only) 로그 저장소에 적재하며, 관리자 화면·API 어디에도 수정·삭제 기능이 없습니다.
  • 활용: 차단 로그 탭에서 기간·대상 시스템·탐지 유형·계정으로 조회하고 엑셀(CSV)로 내보낼 수 있습니다.

4. 판정 DB 갱신 및 정기 시험

  • GeoIP 국가 DB·KISA 할당 정보는 매주 자동 갱신, IP 평판 DB 는 매일, Tor 출구 노드 목록은 1시간 주기로 동기화합니다.
  • 갱신 실패 시 보안 담당자에게 알림이 발송되고 직전 버전으로 판정을 계속합니다.
  • 매월 1회 3개 시스템 × 5개 유형(국내 허용·국외·VPN·프록시·Tor)을 실제 접속으로 시험하고 결과를 접속 시험 탭에 기록합니다.

5. 예외 정책

예외 없음 해외 출장·협력사 포함 예외 IP 등록 불가
  • IP 화이트리스트(보안 정책)는 관리자 접근을 좁히는 용도로만 쓰이며 국외 IP 를 통과시키지 못합니다.
  • 최고 관리자를 포함한 모든 이용자에게 동일하게 적용하며, 차단 해제 기능을 제공하지 않습니다.

차단 로그 상세

차단 로그는 변경·삭제가 불가능한 감사 로그이며 3년간 보관됩니다. 국외·우회 접속은 예외 없이 차단되므로 차단 해제 기능을 제공하지 않습니다.
